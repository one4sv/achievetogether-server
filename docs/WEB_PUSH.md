# Web Push и напоминания

Клиент получает публичный ключ через `GET /push/config`. Сервер использует `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY` и `VAPID_SUBJECT` из окружения. Доступность определяется ответом конфигурации. Приватный ключ остаётся на сервере.

## Подписка и доставка

Клиент синхронизирует подписку и язык через `POST /push/subscribe`; для проверки и удаления служат `GET /push/status` и `POST /push/unsubscribe`. Подписка привязана к сессии. Общий Service Worker обрабатывает Push, переход из уведомления и кэш публичных обоев.

`services/habitReminderWorker.js` и `services/planReminderWorker.js` отправляют напоминания по расписанию. Язык хранится в `at_push_subscriptions.language` и выбирается отдельно для каждой подписки. Для прежних подписок используется русский до синхронизации клиентом.

`utils/mentions.js` проверяет ник среди доступных участников беседы. Для обычного сообщения учитываются общие настройки, уведомления сообщений и настройка беседы. Для упоминания действуют общие настройки и переключатель упоминаний; упоминание может доставляться из заглушённой беседы.

## Проверка

Проверить `tests/mentions.test.js`, `tests/reminder-locales.test.js` и `npm test`. На тестовом аккаунте отдельно проверить истёкшую сессию, недействительный endpoint, два языка на разных устройствах и переход из уведомления при закрытом приложении. Для физического iPhone проверять установленное на домашний экран PWA. Клиентские действия описаны в [Web Push](https://github.com/one4sv/AT/blob/main/docs/WEB_PUSH.md).
